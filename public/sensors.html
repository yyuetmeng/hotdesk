Bulk link from a spreadsheet

Where sensors send their readings

Set one of these up once in the system your sensors report to. Send the sensor key in the X-Api-Key header.

  1. The Things Stack (TTN): Integrations → Webhooks → Add webhook → Custom. Base URL , enable Uplink message, add header X-Api-Key.
  2. ChirpStack v4: Application → Integrations → HTTP. Endpoint , add header X-Api-Key, JSON encoding.
  3. Anything else (your own gateway or bridge): POST JSON to as {"sensorId": "…", "presence": true}.
